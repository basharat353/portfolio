# Basharat Umar: Portfolio

Simple static website (HTML + CSS + JS). Koi install nahi chahiye.

## Kholna
`index.html` par double-click karein, browser mein khul jaye ga.

## Apni details dalna
`script.js` ke sab se upar `CONFIG` block mein ye likhein:
- email, WhatsApp number (92 se shuru), GitHub, LinkedIn
- har project ka **live** link (Netlify/Vercel) aur **code** link (GitHub)

Jo link khali chhorein ge, wo button khud chhup jaye ga.

## Online karna (Netlify, free)
1. https://app.netlify.com/drop kholein
2. Poora `my-portfolio` folder us page par drag karke chhor dein
3. Link mil jaye ga, misal `basharat-umar.netlify.app`

## Screenshots
`images/` mein har project ka asli screenshot hai. Project badle to naya screenshot isi naam se rakh dein.
